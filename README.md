# Actividad 5 – Programación Orientada a Objetos con TypeScript

Este repositorio contiene 5 ejercicios resueltos aplicando los pilares de la Programación Orientada a Objetos usando TypeScript y Vite.

## 🔀 Estructura por ramas

- `ejercicio1`: Clase `CabeceraPagina` con manipulación visual del DOM
- `ejercicio2`: Clase `Calculadora` con interfaz visual y operaciones matemáticas
- `ejercicio3`: Clase `Canción` con uso de getters y setters
- `ejercicio4`: Clase `Cuenta` con validaciones de depósito y retiro
- `ejercicio5`: Clases `Persona` (abstracta) y `Empleado` (herencia + validación)

Cada ejercicio está aislado en su propia rama para facilitar su revisión y mantenimiento.

## ✅ Tecnologías usadas

- TypeScript
- HTML/CSS
- Vite
- Git & GitHub
